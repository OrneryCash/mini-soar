หลักการเปิดเผยข้อมูล (PDPA)

ข้อความ LINE อ้างอิงเหตุการณ์ ไม่ใช่ตัวข้อมูล — ส่งเฉพาะสิ่งที่บอกว่าเกิดอะไรและไปดูที่ไหน รายละเอียดอยู่ในหน้าจอของคลินิกภายใต้การควบคุมการเข้าถึง การส่งข้อมูลส่วนบุคคลไปยัง LINE ถือเป็นการเปิดเผยต่อบุคคลที่สามตาม PDPA มาตรา 37(4)

ขั้นตอนตั้งค่าครั้งแรก (ประมาณ 10 นาที)

  1. สร้าง LINE Official Account (ฟรี) ที่ LINE Official Account Manager
  2. สร้าง Messaging API channel → คัดลอก channel access token
  3. เพิ่ม OA เป็นเพื่อน หรือเชิญ OA เข้ากลุ่ม (ต้องเปิด “Allow joining group chats” ก่อน)
  4. วาง token และ target ID ในไฟล์ config.local.yaml แล้วรีสตาร์ตบริการ
  5. กลับมาที่หน้านี้ กด ทดสอบการเชื่อมต่อ → ควรเห็น token OK และ payload valid
  6. กด ส่งข้อความทดสอบจริง เพื่อยืนยันว่าข้อความเข้าจริง

⚠️ ห้ามวางโทเคนในไฟล์ config.yaml — ไฟล์นั้นถูกติดตามด้วย git และ repo เป็นสาธารณะ ใช้ config.local.yaml เท่านั้น (อยู่ใน .gitignore)
